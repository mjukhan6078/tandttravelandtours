# T&T Travel and Tours Landing Page Design

**Date:** 2026-06-16
**Author:** T&T Travel and Tours

## Overview
This document describes the design for the T&T Travel and Tours landing page, a modern, responsive website showcasing Umrah, Hajj, and travel services.

## Technology Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS
- Shadcn UI components
- Lucide React icons

## Page Structure

### 1. Header & Navigation
- Logo (provided: /home/junaidmsi/Documents/17931-removebg-preview.png)
- Navigation links: Home, Services, Packages, Contact
- Mobile-responsive hamburger menu

### 2. Hero Section
- Compelling headline about Umrah, Hajj, and travel services
- Call-to-action buttons: "Explore Packages" and "Contact Us"
- Background image of Kaaba or beautiful travel destination

### 3. About Section
- Brief company introduction
- Key differentiators (experience, trust, quality service)

### 4. Services Section
- Cards for each service:
  - Umrah Packages
  - Hajj Packages
  - Tours & Travel
  - Visa Assistance
  - Hotel Booking
  - Flight Tickets
  - Ziarat Services
- Each card has icon, title, short description, and "Learn More" link

### 5. Featured Packages Section
- Grid of package cards (Umrah, Hajj, Tours)
- Each card shows: package name, duration, price, key features, "View Details" and "Book Now" buttons
- Search and filter functionality (by service type, price range, duration)

### 6. Testimonials Section
- Customer reviews with photos and ratings
- Carousel or grid layout

### 7. FAQ Section
- Collapsible accordion with common questions
- Covers booking process, payment, visa requirements, etc.

### 8. Contact Section
- Contact information: phone, email, address
- WhatsApp contact button (direct link)
- Contact form (name, email, phone, message)
- Google Maps integration (optional)

### 9. Footer
- Logo, quick links, social media, copyright

## Design Style

### Color Scheme
- Primary: Deep blue (#1e3a8a) - trust, professionalism
- Secondary: Gold (#f59e0b) - luxury, premium feel
- Neutral: White, light grays - clean, modern

### Typography
- Clean sans-serif (Inter)
- Clear visual hierarchy with H1-H6

### Layout
- Responsive grid
- Plenty of white space
- Smooth animations and transitions

## Key Features
- Fully responsive (mobile, tablet, desktop)
- SEO optimized with Next.js metadata
- WhatsApp integration (direct chat link)
- Contact form with email integration
- Package filtering and search
- Accessible design

## Success Criteria
- All sections implemented and functional
- Responsive across all device sizes
- Fast page load times
- SEO-friendly structure
- Easy to maintain and update
